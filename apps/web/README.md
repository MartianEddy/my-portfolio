# EDBOT Engineering — Web

Next.js App Router portfolio for Edwin Wakibari, positioned around AI security and agent systems.

## Stack

- Next.js 15 / React 19 / TypeScript
- Tailwind CSS 3.4 with a small layer of custom component styling
- Lucide icons

## Requirements

- Node.js 20.9 or later
- npm 10 recommended

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
```

## Routes

- `/` — home
- `/engineering` — project index
- `/research` — research agenda
- `/security-lab` — Sentinel overview and current boundaries
- `/engineering-notes` — notes index
- `/about` — professional background and contact

## Content integrity

Project statuses distinguish implemented prototypes, MVPs under hardening, project prototypes and work whose implementation evidence still needs review. Do not remove these distinctions without confirming the underlying source, tests and personal contribution. The site does not claim Sentinel is production-ready.

The canonical domain has not been selected. Metadata therefore avoids a fabricated `metadataBase`. Add a sitemap after the production domain is confirmed.
